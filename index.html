How It Works

1. Create and Type

Open a plain text file. Type projects with colons, tasks with dashes, add @tags. Auto-formatting handles the rest.

2. Organize and Fold

Drag to reorder, indent for sublists. Fold projects to collapse, focus to isolate, filter to refine.

3. Search and Act

Use sidebar saved searches or type queries with dates and tags. Edit inline with outliner speed and power.

4. Extend and Sync

Apply themes, run scripts via API. Sync files via iCloud, Dropbox, or Git—seamless across devices.
